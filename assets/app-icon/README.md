# Oracle Vector app icon

The Oracle app tile, like every Oracle app: a rounded square in the app's colour (`#ff6a3d`) with the
Oracle four-pointed star and the letters "Ve".

Drawn by `Oracle-suite/tools/make_app_icon.py`, which writes the SVGs, the 1024 px PNG, the `.ico`, the
`.icns` and the `hicolor/` sizes.
