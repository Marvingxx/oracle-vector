Oracle Vector portable mode

While this file sits next to oracle-vector.exe, Oracle Vector keeps its preferences, swatch and
graphic style libraries, added fonts, crash-recovery files and logs in the Oracle VectorData folder
beside it, and writes nothing to %APPDATA%. Copy the whole folder to move Oracle Vector with its
settings. The first time Oracle VectorData is created, any settings already in
%APPDATA%\Oracle Vector are copied into it; the originals are left where they were.

Keep this folder somewhere only you can write to: whoever can write here decides your settings,
including the plug-ins and fonts folders Oracle Vector loads from, and the Data Recovery copies of
your unsaved documents are kept here too.

Delete this file to use the normal per-user settings folder (%APPDATA%\Oracle Vector) instead.
If Oracle VectorData can't be written (for example on a read-only drive), Oracle Vector logs a
warning and uses %APPDATA%\Oracle Vector instead.
